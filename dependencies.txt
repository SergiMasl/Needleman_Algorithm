## Dependencies: (Updated 3/19/2026)

#python=3.11

- Python 3.11 is needed, as it is the main language of this program and needed to run the code/syntax properly.
All files have been coded using Python, located in libraries to be executed as modules by the main.py file. 
 
===============================================================================================================

#NumPy

- NumPy has been utilized for the creation and initialization of matrices. For creating the output table in the scrolling_output.py module, NumPy is needed and preferred as it can perform the basic function of creating the initialized matrix, ready to be filled in with passed data from the parsing.py program. 

===============================================================================================================

#argparse 

- Used to create command line interface options and argument-handling. Command-line interface options include 
types, default values, and expected values. 

===============================================================================================================

#sys

Used to provide variables that interact closely with the Python interpreter and its runtime environment. 
Implemented to make sure the output prints properly to terminal, and can exit with either a 0 or 1, indicating
success or failure.
